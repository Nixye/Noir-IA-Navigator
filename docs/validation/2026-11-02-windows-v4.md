# Entrega Windows 0.4 — 2026-11-02

## O que foi implementado

Permissão total opcional no assistente autoriza antecipadamente todas as ferramentas de navegador implementadas. Cliques e formulários suportados não solicitam confirmação. Há indicação de modo ativo, revogação, Interromper e limite de 32 ações por pedido. O modo granular continua disponível com revisão de cliques e8 ações. A concessão não é persistida entre conversas e não cria ferramentas de terminal, filesystem ou execução arbitrária de scripts. Dados de páginas permanecem não confiáveis.

O despacho de ações acontece depois de processar a interface do frame, para respeitar Interromper/revogação antes da próxima ação. O shell conserva validação de escopo/geração, IDs, limites e broker. Os valores dos campos de senha não são incluídos na observação; no modo total, é possível enviar os formulários já preenchidos que o navegador suporta.

A compatibilidade aumenta em pontos concretos:

- Recursos públicos de CDN, sem credenciais e sob DNS fixado, bloqueios de redes privadas/conteúdo misto e AppContainer obrigatório.
- Folhas externas em assets do protocolo 3, aplicadas em sua posição original no DOM, com limites cumulativos. CSS não é injetado como HTML.
- CSS relative/absolute, rem pela fonte raiz, viewportunits, visibilidade, nowrap, tabelas simples e dimensionamento de controles.
- Aparência CSS dos controles na interface e CPU, sem bordas/caixas duplicadas. Hidden não ocupa largura. Select simples inclui opções limitadas, grupos desabilitados, valor no DOM e evento change. O parser HTML aceita fechamento implícito de option/optgroup.
- PNG/JPEG/WebP/GIF primeiro frame, redução de imagens maiores, Data URLs e SVG estático restrito com resolutores externos desabilitados.
- try/catch/finally, switch, do/while, labels, vírgula, new de funções próprias, protótipos limitados, call/apply, helpers de objetos e aliases reais de métodos de document.
- Exceções ordinárias preservam efeitos anteriores; Resource continua com rollback e desativação, sem poder ser capturado pela página.

## Verificações realizadas

- cargo check --workspace --all-targets --locked.
- cargo fmt --all --check.
- cargo clippy --workspace --all-targets --locked -- -D warnings.
- Build release do workspace com Cargo.lock.
- Carregamento diagnóstico pelo CLI e motor próprios das URLs públicas abaixo, gerando display list e raster CPU. Não foi utilizado outro motor para apresentar o conteúdo.

Não foi executada a suíte de testes, conforme solicitação do usuário. Novas verificações de fronteira e regressão foram adicionadas ao código e seus alvos compilam, mas não possuem resultado de execução nesta entrega. Inferência real do modelo e interação completa com ferramentas da IA não foram reavaliadas. Os resultados históricos das versões anteriores não demonstram comportamento funcional novo.

## Limites que permanecem

Compatibilidade total não está implementada. Google Search ainda exige recursos ausentes. Regex, eval, classes/campos privados, módulos, Promises/async, Fetch e várias Web APIs continuam pendentes. A ausência de uma API causa diagnóstico; ela não é simulada para aparentar sucesso.

CSS ainda não cobre algoritmos completos de Flex/Grid/tabelas, z-index, fixed/sticky, clipping geral ou todos os seletores. Fontes Ubuntu/egui não oferecem fallback universal, e idiomas/símbolos podem apresentar glifos ausentes. Select múltiplo/listboxes, POST, cookies e validação completa de formulários não estão implementados. O SVG aceito é um subconjunto estático de imagens, sem fontes, scripts ou recursos externos.

Os budgets e a prova de isolamento continuam necessários. O [ADR 0008](../adr/0008-authorized-subresources.md) registra a expansão de subrecursos autorizados; os [ADRs0006](../adr/0006-ai-browser-tools.md) e [0007](../adr/0007-script-error-semantics.md) registram concessões da IA e semântica de erros.

## Avaliação manual sugerida

No assistente, ative Assistente de navegação e depois Permissão total. Envie uma tarefa com abas e cliques; verifique que não há revisão por ação e que Revogar/Interromper cancelam o encadeamento. O modelo local pode errar no planejamento ou formato JSON.

Experimente as iniciais de Google/Wikipedia, o seletor de idiomas e as fixtures positioned-layout.html, javascript-compatibility.html e image-formats.html. Use os limites descritos para distinguir melhoria de layout de uma aplicação Web inteiramente funcional.
